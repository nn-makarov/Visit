# AutoPlastic — лендинг студии кастомного пластика

Одностраничный сайт с формой заявок и админ-панелью. Без фреймворков и БД: PHP 8 + JSON-файлы.

**Стек:** HTML5, Bootstrap 5, vanilla JS (fetch/FormData), PHP 8, Apache (.htaccess)

## Возможности
- Лендинг: услуги, сценарии клиентов, этапы работы, портфолио-карусель, форма заявки с загрузкой фото/STL/STEP
- Приём заявок: валидация, проверка типа и MIME файла, лимит 15 МБ, уведомление в Telegram
- Защита от спама: honeypot, лимит заявок с IP, согласие на обработку данных
- Админ-панель: вход по bcrypt-паролю, поиск и фильтры, смена статуса, удаление, статистика
- Безопасность: проверка ID по шаблону, запрет выполнения PHP в `uploads/`, закрытые служебные папки, обновление сессии при входе
- Визуал (`css/effects.css`, `js/effects.js`): чёрный фон, диагональные световые мазки, которые проявляются при прокрутке, плавный переход видео в фон, тёмные карточки с иконками, галерея-мозаика с лайтбоксом (клавиатура и свайп), свечение вокруг курсора на ПК
- Оптимизация: изображения сжаты с ~11,6 МБ до ~1 МБ, lazy-loading, Open Graph, meta description

## Запуск
1. Скопировать файлы на хостинг с PHP 8+ и Apache (корень домена).
2. В `config.php` заменить `ADMIN_PASSWORD_HASH`: `php -r "echo password_hash('ваш_пароль', PASSWORD_DEFAULT);"`
3. (Опционально) заполнить `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` для уведомлений.
4. Дать права на запись папкам `orders/`, `backup/`, `uploads/`.
5. Админка: `/admin.php`
